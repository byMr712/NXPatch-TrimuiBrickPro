# «Продолжить» первым пунктом в консоли

Дата: 2026-11-26. Реализовано и проверено на консоли.

## Что делает

В списке игр внутри `Roms/<консоль>` первой строкой появляется последняя
игра, в которую играли в этой консоли. Строка выделена белой «пилюлей»
(как выбранная строка) и помечена стрелкой `»`, чтобы отличаться от обычного
списка. Справа показывается обложка этой игры.

- A на этой строке — запуск игры с сохранения.
- Y «ПРОДОЛЖИТЬ» внизу — тот же запуск (штатная подсказка, если сейв есть).
- После выхода из игры строка снова на первом месте.
- В результатах поиска эта строка не участвует.

## Почему стрелка, а не «ПРОДОЛЖИТЬ: <игра>»

Полная строка `ПРОДОЛЖИТЬ: IndestructoTank` не помещается в строку списка:
штатный рендер включает бегущую строку, и на скриншоте начало «ПРО» обрезается.
Вариант `» <игра>` помещается целиком, читается и остаётся в стиле прошивки;
слово «ПРОДОЛЖИТЬ» при этом видно в нижней подсказке Y.

## Как определяется игра

`recents.txt` хранит недавние запуски (новые сверху). Патч берёт самый свежий
recent, чей путь есть в **текущем** списке Directory. Поэтому:

- для склеенных консолей (например, Game Boy + Game Boy Color) находится
  последняя игра именно из видимого списка;
- если в консоли ещё ничего не запускали, строки нет;
- если последняя игра была в другой консоли, в этой строки нет.

## Реализация

- Хук в начале `GameList_handleInput` (0x41d840): на первом кадре нового
  Directory один раз вставляет строку.
- Поиск игры: `Recents_at` (0x4acc20) + `Recents_entryFromRecent` (0x4adc40);
  сравнение пути с записями текущего списка через `strcmp` (PLT 0x407170).
- У синтетической записи:
  - `name` — реальное имя игры (для `Entry_open`, recents, меню);
  - `unique` — отображаемая строка `» <игра>` (рендер берёт `unique`);
  - `alpha = -1` — маркер «это наш пункт»;
  - вставка через `Array_push` + сдвиг items, `alphas.items[] += 1`;
  - `selected = 0`, `start = 0`, `end = min(count, rows)`.
- A на строке: хук `openSelected` (0x416810) выставляет
  `resume.should_resume = 1`, дальше штатный `Entry_open` запускает с сейва.
- Флаг dirty (0x4d7c04) выставляется, чтобы список перерисовался сразу.
- Поиск (`cs_fill`) пропускает записи с `alpha == -1`, поэтому стрелка не
  попадает в результаты.

## Ограничения

- Контекстное меню на этой строке действует на **реальную** игру (удалить,
  переименовать, обложка). «Переименовать» начинает ввод с отображаемой
  строки со стрелкой; при желании это можно скрыть отдельным хуком.
- Строка только в списках под `Roms/` (не в Tools, Collections, Recents,
  поиске и не на карусели консолей).
- Если игру переименовали/удалили, recent отфильтруется при следующем старте;
  строка исчезнет.

## Проверка

- Итоговая сборка: `c49fa01ae2395b9c92b0641b1f1057e5`.
- В Game Boy первой строкой `» IndestructoTank`, белая пилюля, обложка.
- A запускает игру, после выхода строка возвращается.
- Y показывает «ПРОДОЛЖИТЬ» (сейв есть).
